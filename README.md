# Repair Job Logger

A beginner Python console application for registering and managing computer repair jobs.

## Features

- Register repair jobs with unique IDs
- Store customer names, device types, reported problems, repair statuses, and costs
- Generate random repair costs
- View all registered repairs
- Search for repairs by ID
- Update repair statuses
- Display the total number of repairs and the number still pending

## Technologies

- Python
- `random` module

## Purpose

This project was built to practise Python dictionaries, nested data structures, loops, conditional statements, input validation, and basic record management.

##Update

Swapped multiple if statements with functions

## How to Run

Run the program from a terminal:

```bash
python3 repair-job-logger.py
```
